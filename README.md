# Kodalic Website

A premium, modern digital presence for **Kodalic**, a professional web development
and digital technology agency. Built on the visual design language of `startdeed.com`
(a React + TypeScript + Vite recreation), adapted for Kodalic's branding and content.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Included (single-page homepage)

- Responsive navigation with mobile menu
- Kodalic hero section and phone mockup
- Service capabilities marquee
- Value / trust strip
- 3-step "Start a Project" section
- Contact CTA with animated portfolio mockup
- Why-Choose-Kodalic section
- How-we-work process cards
- Comparison table (template / freelancer / generic agency / Kodalic)
- Quality & trust section
- Service carousel
- Testimonial section
- Animated FAQ accordion
- Final CTA and footer
- Scroll reveal animations
- Responsive layouts for desktop/tablet/mobile

## Notes

This is a portfolio demonstration for learning and design purposes. It is not
affiliated with Deed Limited and does not implement real authentication,
payments, or a contact backend. Contact form actions are stubbed to alerts.

Member names, metrics, and client testimonials use clearly replaceable
placeholder content where real data is not yet available — swap them for real
copy before launch.

The imagery is sourced from Unsplash at runtime, so an internet connection is
required for those remote images. Replace the URLs in `src/main.tsx` with local
assets if you want a fully offline build.

Reference design site: https://www.startdeed.com/
